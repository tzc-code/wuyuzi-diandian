## 11:40 追加：免微信可行性最终裁定（应大王之问）
- **正文**：可用最简 6 参直取 —— `biz+mid+idx+sn+chksm+scene`，`key/pass_ticket/uin/sessionid` 全部不需要 → 正文抓取彻底免微信 ✓
- **发现**：不可能免微信。新增实测证据：
  - `chksm` **每次打开都变**（同篇 4 个不同值）→ 服务端按会话签发的凭据，离线无法推导；
  - `sn` 与 `chksm` 缺一不可、且**每篇独有**（去 sn → 空壳页；去 chksm → 「环境异常」风控页；借同号别的篇的 chksm → 空壳页）→ mid 递增探测彻底出局；
  - 文章页 HTML 里只有作者正文的**旧文内链**（mid 4044/4173，均已归档），无「往期列表」模块；
  - `mp/getprofilebizrecommend`、`mp/getbizbanner` → 验证页；`mp/homepage?__biz=` → 错误页；搜狗与搜索引擎均未收录。
- 定性：微信把列表接口锁死在会话凭据上。**「不依赖微信 PC 客户端」可行（第三方持 cookie 服务，需一次扫码）；「不依赖微信登录」不可能。**
